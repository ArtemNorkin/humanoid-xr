# HUMANOID XR

Интерактивное веб-приложение с оригинальной 3D-моделью робота и библиотекой Google Model Viewer.

## Запуск

1. Распакуйте архив.
2. В папке HUMANOID_XR выполните `python -m http.server 8000`.
3. Откройте `http://localhost:8000`.
4. Для AR разместите сайт на HTTPS (например, GitHub Pages) и откройте на совместимом смартфоне.

## Файлы

- `index.html` — страница приложения.
- `styles.css` — адаптивный дизайн.
- `app.js` — ракурсы, вращение, свет, полноэкранный режим и справка.
- `models/robot.glb` — модель робота.
- `blender/generate_robot.py` — скрипт создания сцены Blender.

## Ограничения

Поддержка AR зависит от устройства, браузера и HTTPS. Для Quick Look на iOS может потребоваться отдельный USDZ. Реальное AR-тестирование на телефоне не проводилось. Для сдачи проверьте модель в Blender 5.1, UV-развёртку и PBR-текстуры, а также сделайте собственные скриншоты.
